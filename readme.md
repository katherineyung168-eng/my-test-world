# 凱茵漫遊 AiKY — 台灣旅遊景點互動地圖 Web App

## 📌 1. 簡介

**「凱茵漫遊 AiKY」**是一款專為台灣旅人打造的響應式 (RWD) 互動式旅遊地圖 Web App。採用活潑歡樂的視覺風格與可愛音效，整合 Leaflet.js 與 OpenStreetMap/Esri 雙地圖圖層，全面涵蓋全台 22 縣市及離島熱門景點。

使用者可依地區、類型（自然、美食、夜市、網美等）與關鍵字靈活篩選，並體驗「今天去哪玩？」隨機抽景點與地圖飛躍聚焦。系統內建「多天數行程規劃器」，支援 Day 1～Day 3 分天排序、自訂景點筆記、總歷時預估與地圖實時路線連線 (Polyline)，亦可一鍵開啟 Google Maps 導航與匯出文字清單。

全站資料完全於前端透過 LocalStorage 離線自動儲存，免申請任何 API Key 即可順暢運作，提供流暢直覺的島內探索體驗！

---

## 🌟 2. 主要功能

1. **互動式雙模式地圖**
   * **標準/衛星視圖**：可自由切換 OpenStreetMap 標準圖層與 Esri 高解析度衛星空照圖。
   * **客製化地標與氣泡彈窗**：依景點類別（自然、美食、歷史、網美等）顯示專屬顏色圖示，點擊可預覽照片、評分與詳細資訊。
   * **地圖飛躍聚焦**：搜尋或挑選景點時，地圖會滑順平移放大至目標位置 (`flyTo`)。

2. **多維度景點篩選與搜尋**
   * **全台縣市與五大區域**：涵蓋北部、中部、南部、東部及離島地區。
   * **熱門主題標籤**：支援 `#親子`、`#美食`、`#夜景`、`#古蹟`、`#網美` 等分類標籤與關鍵字搜尋。

3. **智慧多天數行程規劃器 (Itinerary Planner)**
   * **分天數管理**：支援 **Day 1、Day 2、Day 3...** 彈性安排與排序。
   * **地圖實時路線連線 (Polyline)**：自動在地圖上記錄並畫出當天行程景點間的預計行進路線。
   * **自訂景點筆記與時長估算**：可自由新增私人備忘（如「15:00 記得買伴手禮」）並統計總停留時間。
   * **行程匯出/分享**：支援一鍵複製純文字排程清單（方便貼至 Line）或匯出/匯入 JSON 備份檔。

4. **互動趣味與個人化**
   * **「今天去哪玩？」隨機抽景點**：帶有歡快動畫與飛躍鏡頭的隨機轉盤功能。
   * **我的最愛（收藏）**：快速點擊愛心收藏想去的地點。
   * **可愛互動音效**：內建 Web Audio 彈跳聲、心形收藏音與歡呼提示音（可自由開關）。
   * **深色/淺色模式 (Dark Mode)**：提供舒適的夜間瀏覽介面。

## 🛠️ 3. 活用的 API 與技術

本 Web App 採用**免 API Key（無須申請付費金鑰）**的純前端輕量化架構：

| 技術 / API 名稱 | 實際用途與實現方式 |
| :--- | :--- |
| **Leaflet.js** | 核心互動地圖 Engine，負責 Marker 標記、Popup 氣泡窗、Polyline 路線繪製與平滑滑動 (`flyTo`)。 |
| **OpenStreetMap & CartoDB Tile API** | 提供免費且清晰的標準電子地圖網格圖磚 (`tile.openstreetmap.org`)。 |
| **Esri World Imagery API** | 切換至衛星模式時，載入 Esri 提供的高解析度全球衛星空照圖磚。 |
| **Google Maps URL API** | 點擊「帶 me 去導航」時，自動生成標準 Google 地圖導航連結 (`https://www.google.com/maps/search/?api=1...`) 直接啟動手機地圖 App。 |
| **Web Storage API (LocalStorage)** | 離線資料儲存，將使用者的「收藏景點」、「多天數行程」與「深色模式偏好」儲存在瀏覽器，關閉網頁資料不丟失。 |
| **Web Audio API** | 原生瀏覽器聲音合成技術，不需載入額外 MP3 音檔即可實時產生可愛的彈跳與歡呼聲。 |
